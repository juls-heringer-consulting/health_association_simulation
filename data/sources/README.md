# Source systems (`data/sources/`)

Everything in this folder is **synthetic** and generated by `python/generate_sources.py`
(seed in `config/settings.toml`). Each sub-folder imitates one source system of a
Kassenärztliche Vereinigung (KV) with its own format and habits. The README in each
folder documents origin, owner, update frequency and known quirks; the generator never
overwrites README files.

## Format quirks vs. data errors

The quirks listed in the READMEs are **format** properties (encodings, number formats,
date notations, header lines) that every loader must handle. They are not data errors.
Deliberately broken data (duplicates, missing values, wrong codes) would be the optional
"data quality injection" phase, which is switched off (`inject_dq_issues = false`).

What the data *does* contain on purpose are realistic **business anomalies** that a KV
department would look for: GOPs billed without a QS permit, practices with unusually high
case values or prescription costs, doctors with too few CME points.

## Same entity, different keys and notations

| Concept | Notations in the sources |
|---|---|
| Quarter | `12025` (billing, KVDT style), `2025Q1` (Honorar XML), `1/2025` (Prüfungsstelle), `Quartal 1/2025` inside free text (finance) |
| Doctor | LANR (most sources), EFN (Kammer) |
| Date | `dd.mm.yyyy`, `TTMMJJJJ` (billing lines), ISO `yyyy-mm-dd`, ISO with UTC offset (APIs), Excel date |
| Decimal | `0,75` / `1.234,56` (German), `0.123934` (XML), amounts in cent (fixed-width) |
| Specialty | Fachgruppe code `01` (register), Arztgruppe `HA` (planning), label `Hausarzt` (TSS API) |
